# Incident Response Playbook

## Scenario

Brute Force Attack

## Detection

More than five failed login attempts from a single IP address.

## Investigation

1. Review login activity.
2. Identify affected accounts.
3. Check for successful logins.

## Containment

1. Block source IP.
2. Reset passwords.
3. Enable MFA.

## Recovery

1. Monitor account activity.
2. Verify account integrity.

## Lessons Learned

Review authentication controls.
