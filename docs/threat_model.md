# Threat Model

## Assets

- Cloud Audit Logs
- User Accounts
- Storage Buckets
- Security Reports

## Threat Actors

### External Attacker

Goals:
- Access cloud resources
- Escalate privileges
- Expose sensitive data

### Insider Threat

Goals:
- Abuse permissions
- Access restricted data

## Threat Scenarios

### Brute Force Login

Risk: High

### Privilege Escalation

Risk: High

### Public Bucket Exposure

Risk: High

### Cloud Reconnaissance

Risk: Medium
